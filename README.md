# odin-recipes

This is a basic recipe website for The Odin Project.

For now it will probably look ugly, but that is not the point. The point is to practice HTML properly: pages, links, images, lists, and a simple folder structure.

I will make an index page with links to a few recipes. Each recipe page will have an image, a description, ingredients, and steps.

With this project I want to get more comfortable writing HTML and using Git/GitHub for my projects.
